# PHYLLO v1.1-C — Release notes and limitations

This package contains a provisional corrected partition and historical evidence. It does not include original PlantSeg photographs or masks.

The original frozen statistical script requires withheld reviewer-level records for the manual precision audit. Consequently, the complete original pipeline is **not independently executable using only this public package**. Published aggregate human-review results are supplied for inspection but cannot be independently reconstructed from individual decisions. No claim of full public reproduction is made.

The 860-item AI-assisted preliminary assessment classifications are not deposited and must not be described as independent human validation.

The v1.1-C test population differs from the original fixed cohort and the earlier corrected v1.0 test population. Cross-partition performance comparisons are descriptive rather than paired causal comparisons.

**Release clearance pending:** Confirm rights to distribute all derived records, and the target journal's policy concerning CC BY-NC 4.0 for secondary derived data, before publishing. The included source documents retain their release-candidate language until approval.

Use `MANIFEST.sha256` to verify all included files. The original 191 evidence files are unchanged.
