# Duplicate-review rubric (C1–C5 / U)

Revision-stage protocol, PHYLLO major revision, written November 2026 for this review.
It was not used in, and does not retrospectively define, the earlier binary review.

Work independently. Do not consult the other reviewer or any file other than this rubric,
your sheet and the images in `review_assets/`. For each row enter exactly one code in the
`category` column (no other text); use `notes` for a short justification where helpful.

| Code | Category | Assign when |
|---|---|---|
| C1 | Identical copy | Same photograph; only resolution, compression or file format differ. |
| C2 | Edited copy | Same photograph after crop, padding, flip, rotation, colour/contrast change, or added text, border or watermark. |
| C3 | Same specimen, new photograph | A different exposure of the same leaf, fruit or plant (e.g. consecutive frames, zoom or small viewpoint change), demonstrated by matching individual lesions, vein patterns or leaf margins. |
| C4 | Same scene, different specimen | Same setting, background, lighting or photographic series, AND you can see that lesions and leaf outlines do not correspond. |
| C5 | Unrelated | Different photographs with no shared specimen or scene; any resemblance is limited to disease appearance or composition, and you can see that they are not the same specimen. |
| U | Unresolved | You cannot reach C1–C5 with confidence. This includes: the images may show the same specimen or photograph but the matching evidence is insufficient or ambiguous; the identity of the specimen is unclear; or image quality (size, blur, occlusion) prevents a judgement. |

Decision rules
1. Decide C1/C2 first: if every structure in one image appears in the other with the same
   geometry up to crop, flip or rotation, it is the same photograph.
2. C3 requires at least two independent matching features (e.g. a distinctive lesion cluster
   AND a leaf-margin defect). Similar symptoms alone are not sufficient.
3. C4 and C5 also require positive evidence: assign them only when you can see that the
   specimens differ. If a match is possible but you can neither demonstrate it nor rule it
   out, record U. Do not resolve such pairs as C4 or C5.
4. Disease, plant species and image quality do not by themselves determine the category.
5. U is a valid answer, not a failure. Every U is referred to adjudication.
6. Codes must be typed exactly: C1, C2, C3, C4, C5 or U.
